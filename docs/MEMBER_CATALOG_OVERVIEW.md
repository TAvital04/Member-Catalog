Welcome to the **UCF Member Catalog** project documentation.

## 📚 Documentation Index

> **For Software Engineers & Maintainers**

## 🚀 Quick Launch

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser to view the application.
To run the automated test suite:

```bash
pnpm test
```
